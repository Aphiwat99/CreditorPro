3.รายการค้างชำระ เมือกดปุ่มยอดรวมระบบจะพาไปที่หน้ายอดค้างรวมทั้งหมดซึ่งมีรายชื่อลูกหนี้ยอดค้างชำระและยอดรวมค้างชำระ

4.ยอดรวม เมื่อกดระบบจะพาไป ที่หน้ารวมยอดทั้งหมดของเจ้าหนี้เป็นหน้าสรุปยอดเงินของเจ้าหนี้ว่าแต่ละเดือนปล่อยเท่าไหร่และนำมาสรุปตอนสิ้นเดือนว่าเก็บเงินต้นเงินดอกได้เท่าไหร่ต่อเดือน

5.ดอกเบี้ย เมือกดจะพาไปหน้าสรุปดอกเบี้ย
